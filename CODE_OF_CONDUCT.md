# Code of conduct

This policy applies to project issues, pull requests, reviews and other project spaces. Treat participants respectfully, make criticism about behavior or technical work, and allow people to correct mistakes. Harassment, discriminatory language, threats, sexual attention, disclosure of private information and deliberate disruption are unacceptable.

Maintainers may edit or remove abusive material, restrict participation or exclude a participant. They should consider the severity and recurrence of the behavior, explain the decision to the affected participant where safe, and protect the reporter's privacy. Maintainers are subject to the same expectations.

For a concern, contact a repository maintainer through a private contact method they have made available. If none is available, open an issue requesting a confidential contact **without naming affected people or posting the allegation**. Security vulnerabilities use the separate private process in [SECURITY.md](SECURITY.md). If a complaint concerns the responding maintainer, request review by another organization administrator; do not send sensitive details publicly. An affected participant may request reconsideration with relevant new information.
